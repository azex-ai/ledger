## 实现

### 测试 fixture 的真实 cluster 隔离

`SetupIsolatedRawDB` 供会删除 cluster-wide role 的 full migration roundtrip 使用。可选 `LEDGER_TEST_ISOLATED_DATABASE_URL` 与普通 fixture 的 server 必须具有不同的 `pg_control_system().system_identifier`；不同数据库名、端口或 URL 字符串不能充当隔离证明。相同 ID、查询失败、缺少权限均 fail closed。未配置时自行启动 PG17 container，独立于普通 `DATABASE_URL`，用 `t.Cleanup` 先删除该测试数据库、再终止容器。两类 URL 都兼容既有 `pgx5://` 输入。

复用已有 flock，仅互斥 container startup。安装的官方 testcontainers PostgreSQL v0.44.0 `BasicWaitStrategies` 同时等待最终启动日志和映射端口，修复默认 Run 没有等待策略的启动空窗。启动上限 2 分钟、身份读取 15 秒、建库 20 秒、删库 5 秒、容器终止 20 秒；失败路径也清理已创建容器。普通共享 container 仍由 Ryuk 在测试进程退出时清理。未新增依赖、未改生产 Migrate / advisory locks / 历史 SQL，未用 `-p1`、重试或 skip 掩盖故障。

roundtrip 先保留普通 SetupDB 的真实 canary currency 和 `ledger_owner` 对象依赖，记录 role OID / table owner，然后在另一 cluster 执行 Up → Down → Up，最后验证普通库的行、role OID 和 owner 全部不变。测试环境约束写入新 `docs/TESTING.md`，README 测试段与 Makefile 提示同步；没有创建不存在的 deployment.md。只有显式 `-short` 跳过 PG；无 Docker 的完整套件需两个独立初始化、专用的测试 cluster。system identifier 的依据为 [PostgreSQL 17 官方文档](https://www.postgresql.org/docs/17/functions-info.html#FUNCTIONS-CONTROLDATA)。

### 公共 journal 幂等边界的时间精度

固定 `.123456789` 的真实 PG 回归确认：pgx 落库为 `.123456`，原 `time.Equal` 比较未截断的 input 导致重复请求 ErrConflict。修复只在 `ensureJournalMatchesInput` 将显式 EffectiveAt 按 `time.Microsecond` floor 后比较，与既有 I-46 signature domain 一致；zero/default 仍不参与显式时间比较。不改示例时钟、签名域、历史数据或迁移。

新测试覆盖 pool unsigned / signed、caller tx unsigned、Authorize + PostAuthorized pool / tx 五条路径，每条八组：原始纳秒、同微秒 `.123456289`、已对齐时间、同 instant 的时区、前后跨微秒、金额变化、zero/default。重放复用 UID；冲突仍被拒；journal / entry / rollup 行数和余额不增加。signed Capture 另验证重放后 verified balance 80、held 0、settled 20 与 receipt 数不变。`core/journal.go` 与 INVARIANTS 同步精度契约。

### 前端静态 gate 与真实重复分录

完整 baseline 扫描是 10 个文件：三处注释文本误报，以及七个文件里的八处 JSX index key；gate 的终端输出只列前五个 key 命中，不能据此缩小总数。OpenAPI 描述改源文件再 codegen，两个 Classification 页面仅改注释措辞。

两种 skin 的 Templates preview 共用私有 helper，以全部 wire 分录字段（holder / currency / classification / entry_type / amount）及同内容出现序号构造 key，保留合法重复、顺序和原对象。没有宣称 wire 不提供的隐藏身份。静态 skeleton 采用明确的 row / header-cell 布局槽 ID，保留数量、className 和 DOM；未改 index 变量名绕扫描、未引入 random key、未弱化 gate。新增两项真实组件回归验证重复分录、重排后的 DOM 身份、总额和无重复 key 警告；没有为注释或静态槽位堆镜像测试。
