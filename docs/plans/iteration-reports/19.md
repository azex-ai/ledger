- SDK numeric holder 限界与稳定宿主映射保留：不完整支持 int64、不截断/隐式重映射；response 校验失败不代表服务端写入没发生。记录实际 error name/code/location，未杜撰导出的 error constructor。
- Task 9 迁移清单落入 BREAKING/两个 SDK 指南：booking metadata 是 string map；旧导出 DTO 保留但不是 client 入参来源；推荐 `Parameters<LedgerClient["createBooking"]>[0]` / `Parameters<LedgerClient["transitionBooking"]>[1]`。preview 多金额走 `amounts`，只有单 string `amount` 简写，混合/缺失以 Promise rejection 拒绝；必需幂等 key 及其 header/body 位置不变。同步方法表遗漏的 key 参数和 `expires_in_sec` wire 字段。
- USD valuation 始终保留原币数量；缺失、过期、未来价格无估值贡献，显式零价不同于缺价，partial subtotal 不充作完整 total，估值不赋予兑换/提现权。ADR 保留历史 BASE 与市场执行设计，仅同步当前 available 校验、Capture/signed/valuation 示例链接；外部市场执行依然未实现。
