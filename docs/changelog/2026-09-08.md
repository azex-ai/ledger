# Changelog - 2026-09-08

## 报价 JSON 校验与兑换明细修复

**类型**：fix/test/docs
**概述**：拒绝报价数组后的非法 JSON 内容，并在兑换支出行显示目标单位和实际到账金额。

**详情**：
- `DecodeConversionQuotes` 在读取报价数组后再次解码，严格要求 `io.EOF`；拒绝多余闭合符、第二个 JSON 值和垃圾尾部，允许合法尾随空白。`JournalInput.Validate` 同步阻止这些异常报价写入。
- 共享 `describeQuote` 使用记录中的 `target_amount` 和目标 `unitLabels`，例如 `1 USDC × 1000.5 → 1000 credits`；前端不重新计算或舍入。多条报价以分号分隔，shadcn / HeroUI 报价文字均允许换行。
- 回归覆盖 JSON 尾部的 8 种情况、精确 decimal 字符串、目标单位回退，以及两种皮肤在只显示支出行时的完整兑换结果。

**验证**：JSON 用例先复现 3 种漏拦截，再通过定向 race 测试；`golangci-lint run ./core/...` 无问题。根模块 `go build ./...`、`go vet ./...`、`go test ./... -count=1` 通过；React 包 build、typecheck、43 个文件 / 250 项测试通过。通用扫描仍报告既有的 error 丢弃、环境变量读取和 TS 注释 / index key 命中，本次未改动这些位置；不宣称通用 gate 全绿。
