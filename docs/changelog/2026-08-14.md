# Changelog - 2026-08-14

## [11:10] 深度审计修复：安全默认、资金事务、API contract 与发布链路

**概述**：完成独立库全量审计后的集中修复。生产配置改为 fail-closed；advisory lock 获取失败不再绕过单飞；`RunInTx` 补齐 transaction-bound adapter、panic 原样传播与可靠 rollback；余额批量读取从逐 classification 查询改为 checkpoint + delta 单查询。地址注册历史扫描改为 PostgreSQL durable queue，以 lease、`SKIP LOCKED`、分块进度和退避重试跨重启恢复，并支持从 factory deployment block 开始。

**API / SDK**：统一 wire envelope 为 `{code,message,data}`（成功 `message:null`，失败 `message:{text,fields?}` / `data:null`），删除漂移的根目录 OpenAPI 副本，补齐 journal / entry `effective_at` schema；React SDK 识别 HTTP 200 内的 business error、默认 timeout，并为 mutation 自动生成且在 retry 中复用 `Idempotency-Key`。

**交付与依赖**：生产 Helm 默认通过 pre-install/pre-upgrade Job 执行 migration，serving pod 默认不持有 DDL；integration tests 改为每个 test process 共享 container、每个 test 独立 database；移除不可发布的本地 nested-module replace。升级 Go 1.26.6、`x/crypto`、gRPC、Next.js 等依赖，production npm audit 与 Go symbol vulnerability scan 均归零。

**验证**：`go test ./...`、核心包 `go test -race`、EVM 子模块 test/vet、`golangci-lint`、两模块 `govulncheck`、`sqlc diff`、Helm lint/template、React 133 tests/typecheck/build/ESLint、OpenAPI codegen deterministic check、`npm audit --omit=dev` 全部通过。
